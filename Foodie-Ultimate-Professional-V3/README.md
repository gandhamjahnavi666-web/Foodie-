# Foodie Ultimate Professional V2

A polished **frontend-only online food delivery system** built with HTML5, CSS3 and pure JavaScript.

## Showcase features
- Smart recommendation engine based on browser-side activity/order history
- Mood-based food discovery: Hungry, Spicy, Healthy, Sweet, Quick Bite, Chill
- Surprise Me random food picker
- Build Your Own Combo with automatic demo savings
- Order Together group-room simulation with shareable code
- Foodie Rewards points + daily bonus
- Eco Delivery reward option
- Voice search using Web Speech API when supported
- Search suggestions
- Dark mode
- Browser geolocation demo
- Live-style delivery partner tracking + ETA
- Offers/coupons
- Cart quantity management and transparent pricing
- Login/signup using localStorage
- Checkout scheduling/payment/tip UI (demo only)
- Order history + reorder
- Responsive mobile/tablet/desktop design

## Run
Open this folder in VS Code and use **Live Server** on `index.html`.

## Important
This is a college frontend project. Real payment processing, restaurant APIs, live GPS, Google Maps, push notifications and true multi-user group ordering require a backend/API integration. The current features are intentionally simulated in the browser.
